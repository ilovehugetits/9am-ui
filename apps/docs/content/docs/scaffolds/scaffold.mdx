## What is already wired

`main.tsx` installs smooth scroll, boots
[i18n](/docs/nui/i18n), and mounts the app inside a
[`VisibilityProvider`](/docs/nui/visibility). `index.html` carries the pre-paint
theme script. `postcss.config.js` has `postcss-color-converter` — both
[CEF non-negotiables](/docs/cef#the-two-non-negotiables) are satisfied out of
the box.

## The one file to edit

```ts title="web/src/nui.config.ts"
export const nuiConfig = {
  resourceName: "my-script",
  themeStorageKey: "my-script:theme",
  defaultTheme: "dark",
};
```

<Callout type="warn">
  Keep the `localStorage` key in `index.html` in sync with `themeStorageKey`.
  The inline script runs before first paint to avoid a theme flash, and it cannot
  read the config module.
</Callout>

## It is not managed after this

`9am-ui check` ignores everything the scaffold writes. It is a starting point,
not a tracked artifact — change it freely.
