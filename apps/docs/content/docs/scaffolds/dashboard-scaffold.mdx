Roughly this, as editable source rather than a component:

An `App.tsx` that composes [`AppShell`](/docs/components/app-shell),
[`DashboardHeader`](/docs/components/dashboard-header) and
[`PageTransition`](/docs/components/page-transition) with the tab state already
wired, and an `Overview.tsx` page of
[`StatCard`](/docs/components/stat-card)s inside a
[`Viewport`](/docs/components/viewport).

## It replaces the starter App

This overwrites the `App.tsx` from [`@9am/scaffold`](/docs/scaffolds/scaffold).
Add it immediately after scaffolding, or diff before you overwrite something you
have already changed.

## Where to go from there

Everything is yours to edit. The parts most people change first:

- **The tab array** — add pages, remove the ones you do not need, and filter it
  by permission rather than disabling triggers.
- **`Overview.tsx`** — the stat cards are placeholders reading nothing. Wire them
  to [`fetchNui`](/docs/nui/nui).
- **The avatar** — a mugshot `<img>` in the header chip.

## Not managed

Like the base scaffold, `9am-ui check` ignores it. It is a starting arrangement,
not a tracked artifact.
