## Installing

Each icon is added individually:

```bash
bunx shadcn@latest add @9am/icon-users @9am/icon-wallet
```

They land in `components/ui/<name>.tsx` alongside the primitives — the split
between `registry/ui` and `registry/icons` only exists in this repo, for
legibility. The export is the camel-cased name plus `Icon`:

```tsx
import { UsersIcon } from "@/components/ui/users";
import { HardDriveDownloadIcon } from "@/components/ui/hard-drive-download";
```

## Two ways to drive one

<Preview name="icons/ref">
  <IconRef />
</Preview>

**Uncontrolled.** With no ref attached, the icon animates on its own hover. Fine
for a standalone glyph.

**Controlled.** Attaching a ref flips `isControlledRef` inside the icon, which
stops it self-triggering and forwards `onMouseEnter` / `onMouseLeave` to you
instead. The parent then decides when to play it:

```tsx
const icon = React.useRef<UsersIconHandle>(null);

<div
  onMouseEnter={() => icon.current?.startAnimation()}
  onMouseLeave={() => icon.current?.stopAnimation()}
>
  <UsersIcon ref={icon} size={20} />
  Employees
</div>;
```

That is the mode tabs, table rows, stat cards and buttons use — the hover target
is the row, not the 20 pixels the glyph occupies.

## The handle

```ts
interface UsersIconHandle {
  startAnimation: () => void;
  stopAnimation: () => void;
}
```

Every icon exports one, named `<Component>Handle`.

<Callout type="warn" title="One exception">
  `icon-refresh-cw` exports its handle interface as `RefreshCCWIconWIcon` — a
  typo in the source. The runtime component is fine; only the type name is
  wrong. Declare the shape locally until it is fixed.
</Callout>

Strokes are painted with `currentColor`, so colour comes from the parent's text
colour. Note that the class lands on the **wrapper**, so `text-primary` works
but a `[&_svg]` selector aimed at the icon will not reach through `motion`'s
elements — which is why
[`DashboardHeader`](/docs/components/dashboard-header) sets an inline `color`
instead.

## Why not an icon library

Every icon here is a `motion` animation with hand-tuned springs, not a static
path. Pulling in `lucide-react` for the shapes and then re-authoring each one to
animate would ship the whole library to a game client to use forty of its
glyphs. These are ~90 lines each and cost nothing that is not used.
