## Inside a viewport header

Drop it inside a `ViewportTitle` so it inherits the header's blur-swap on
scroll:

```tsx
<ViewportHeader>
  <ViewportTitle>
    <SectionHeader
      icon={<UsersIcon ref={iconRef} size={20} className="text-primary" />}
      title={t("ui.players.title")}
      onMouseEnter={() => iconRef.current?.startAnimation()}
      action={<Button>…</Button>}
    />
  </ViewportTitle>
</ViewportHeader>
```

## Why `icon` is a node

The kit's icons animate through an imperative handle, so the caller has to keep
the ref. Taking a component type instead would mean either owning the ref in
here — and losing the ability to fire it from a parent hover — or threading a
callback back out. A node is simpler and puts the trigger where it belongs.
