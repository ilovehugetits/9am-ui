## It is controlled

There is no internal selection state — you own the array:

```tsx
const [selected, setSelected] = React.useState<string[]>([]);

<MultiSelect
  options={CLASSES}
  selected={selected}
  onSelectionChange={setSelected}
/>;
```

## Only one can be open at a time

Radix Popover does not coordinate across instances, so a form with several
multi-selects would happily open all of them. Each instance broadcasts a
`multiselect:open` custom event on `document` with its own `useId`, and every
other instance closes when it sees an id that is not its own.

A custom DOM event rather than shared React state, because the instances have no
common ancestor to hold that state and threading a provider through every form
that happens to use two of these is not worth it.

## Strings

Falls back to `KIT_DEFAULTS` in [`@9am/i18n`](/docs/nui/i18n):
`ui.common.selectPlaceholder`, `ui.common.searchPlaceholder`,
`ui.common.noResultsFound`, `ui.common.nSelected`. The props override them
per-instance.
