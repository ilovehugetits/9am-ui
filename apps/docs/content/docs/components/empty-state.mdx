## Why it exists

Sized and muted to match the empty lists across the 9AM scripts, so "no results"
reads as a **state** rather than as a panel that failed to load. A fixed `h-32`
means the surrounding layout does not jump when the list empties.

```tsx
{players.length === 0 && <EmptyState message={t("ui.players.empty")} />}
```
