A vertical separator takes its height from the flex row it sits in, so the row
needs a height — `h-5` in the example above.

## Not a Radix primitive

This one is a plain `div` rather than `@radix-ui/react-separator`. It renders
`role="none"` when decorative and `role="separator"` with `aria-orientation`
when not, which is the whole of what the primitive was providing — and one
fewer package in a bundle that ships to a game client.
