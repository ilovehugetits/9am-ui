## Line

<Preview name="tabs/line">
  <TabsLine />
</Preview>

No pill background; the active trigger takes `--primary` and grows an underline
from the `after:` pseudo-element. This is what
[`DashboardHeader`](/docs/components/dashboard-header) uses — reach for that
instead of hand-rolling it when you want icons and animation too.

## Vertical

<Preview name="tabs/vertical">
  <TabsVertical />
</Preview>

`orientation="vertical"` moves the indicator to the right edge of the list and
stretches triggers to full width. Set it on `Tabs`; the list and triggers read
it through `group-data-[orientation=vertical]/tabs`.
